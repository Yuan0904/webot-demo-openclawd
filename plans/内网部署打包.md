# 打包 Gateway + Sidecar 为自包含可运行包

## Context

用户需要将项目部署到内网 UOS Debian 10 (Linux x64) 机器上，要求解压即用，无需安装 Node.js、pnpm 或任何构建工具。

当前开发机是 macOS，node_modules 中有平台相关的 native addon（sharp、node-pty 等），不能直接拷贝到 Linux 使用。

## 方案：Docker 构建 + 自包含 tarball

使用 Docker 在 Debian 10 环境中完成依赖安装和编译，最终产出一个 tarball，包含：

```
webbot-standalone/
├── node/                  # Node.js 22 linux-x64 二进制
│   └── bin/node
├── dist/                  # Gateway 编译产物（tsdown 输出）
├── sidecar/dist/          # Sidecar 编译产物 + public/
├── node_modules/          # Linux x64 原生依赖
├── package.json           # 运行时需要
├── webbot.mjs             # Gateway 入口
├── .env.example           # 配置模板
└── start.sh               # 一键启动脚本
```

### start.sh 行为

```bash
#!/bin/bash
DIR="$(cd "$(dirname "$0")" && pwd)"
export PATH="$DIR/node/bin:$PATH"
# 加载 .env
set -a; source "$DIR/.env" 2>/dev/null; set +a
# 启动 Gateway（后台）
node "$DIR/webbot.mjs" gateway run --allow-unconfigured \
  --token "${WEBBOT_GATEWAY_TOKEN:-123}" &
GATEWAY_PID=$!
sleep 3
# 启动 Sidecar
GATEWAY_TOKEN="${WEBBOT_GATEWAY_TOKEN:-123}" \
  node "$DIR/sidecar/dist/index.js" &
SIDECAR_PID=$!
echo "Gateway PID=$GATEWAY_PID, Sidecar PID=$SIDECAR_PID"
echo "访问 http://localhost:3100"
wait
```

### 构建流程（Dockerfile.standalone）

1. 基于 `debian:buster` (glibc 2.28，兼容 UOS Debian 10)
2. 安装 Node.js 22 linux-x64（下载预编译二进制）
3. 安装 pnpm，执行 `pnpm install --frozen-lockfile`
4. 执行 `pnpm build`（tsdown 编译 gateway）
5. 编译 sidecar：`cd sidecar && npx tsc && cp -r src/public dist/`
6. 打包产物到 tarball

### 需要创建的文件

1. `Dockerfile.standalone` — 多阶段构建，产出 tarball
2. `start.sh` — 一键启动脚本
3. `scripts/build-standalone.sh` — 本地执行的构建入口（调用 docker build + docker cp）

### 关键文件

- `webbot.mjs` — Gateway 生产入口
- `sidecar/src/index.ts` → `sidecar/dist/index.js` — Sidecar 入口
- `tsdown.config.ts` — Gateway 构建配置
- `package.json` / `pnpm-lock.yaml` — 依赖锁定
- `.env` — 运行时配置

## 验证

1. 在 macOS 上执行 `bash scripts/build-standalone.sh`
2. 产出 `webbot-standalone.tar.gz`
3. 拷贝到 UOS 机器，解压，编辑 `.env`，执行 `./start.sh`
4. 浏览器访问 `http://<ip>:3100` 发送消息
